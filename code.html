[ PROTOCOL INQUIRIES & SPECIFICATION ] 04 INQUIRIES CATALOGUED

Does this replace manual QA?

expand_more
Simulant catches synthetic state issues and user frustration before internal QA cycles, freeing manual testers for high-judgment exploratory flows.

What does a persona actually do?

expand_more
It reads the visual screen and DOM, reasons through goals with strict mental models, interacts via headless Chromium, and documents cognitive friction.

How do you know a finding is real?

expand_more
Every bug contains a deterministic step-by-step trace and screenshot with highlighted DOM coordinates to reproduce in local dev.

Which sites can it test?

expand_more
Any publicly accessible or localhost staging URL with basic HTTP auth, SSO bypass tokens, or seeded test credentials.
